    About

    The model never writes a pattern. It chooses one value out of a closed enumeration of 43 families, and the compiler turns that value into an automaton.

    A request is understood in two languages, and in no other:

    • enEnglish
    • pt-BRBrazilian Portuguese
    • --every other language is refused

    The engine simulates an NFA, so there is no catastrophic backtracking and the worst case is O(m*n).
